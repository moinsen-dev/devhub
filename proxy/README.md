# DevHub Reverse Proxy

A Caddy-based reverse proxy for local development that gives you pretty URLs like `http://myproject.localhost`.

## Quick Start

```bash
# Create the shared network (one-time)
docker network create shared_proxy

# Start the proxy
docker compose up -d

# Verify it's running
curl http://localhost
```

## How It Works

```
Browser Request
http://myapp.localhost
        │
        ▼ :80
┌───────────────────────────────┐
│      Caddy Proxy              │
│  (this Docker container)      │
│                               │
│  Reads: Caddyfile             │
│  Imports: sites.d/*.caddy     │
└───────────┬───────────────────┘
            │
            ▼ host.docker.internal:PORT
┌───────────────────────────────┐
│    Your Dev Service           │
│  (running on host machine)    │
└───────────────────────────────┘
```

## Adding Projects

### With DevHub (Recommended)

DevHub automatically creates and updates proxy configs:

```bash
cd ~/my-project
devhub init          # Creates devhub.toml
devhub register      # Registers with DevHub
devhub start         # Creates sites.d/my-project.caddy and starts services
```

### Manually

Create a file in `sites.d/`:

```bash
# sites.d/myapp.caddy
cat > sites.d/myapp.caddy << 'EOF'
http://myapp.localhost {
    reverse_proxy host.docker.internal:3000
}

http://api.myapp.localhost {
    reverse_proxy host.docker.internal:8080
}
EOF

# Reload Caddy
docker exec caddy-proxy caddy reload --config /etc/caddy/Caddyfile
```

## Commands

```bash
# Start proxy
docker compose up -d

# Stop proxy
docker compose down

# View logs
docker logs -f caddy-proxy

# Reload after config changes
docker exec caddy-proxy caddy reload --config /etc/caddy/Caddyfile

# Validate config
docker exec caddy-proxy caddy validate --config /etc/caddy/Caddyfile

# List active sites
ls sites.d/
```

## File Structure

```
proxy/
├── docker-compose.yml    # Container definition
├── Caddyfile             # Main config (imports sites.d/*)
├── sites.d/              # Project configs (auto-generated by DevHub)
│   ├── devhub.caddy      # DevHub dashboard routes
│   ├── myapp.caddy       # Your project routes
│   └── ...
└── README.md             # This file
```

## Troubleshooting

### Port 80 already in use

```bash
# Find what's using port 80
lsof -i :80

# Stop it or change the proxy port in docker-compose.yml
```

### Can't reach host services

Make sure your service is listening on `0.0.0.0` or `localhost`, not just `127.0.0.1`:

```bash
# Check what's listening
lsof -i :3000

# Many dev servers need explicit host binding
npm run dev -- --host
```

### Config changes not reflected

```bash
# Reload Caddy
docker exec caddy-proxy caddy reload --config /etc/caddy/Caddyfile
```

### DNS not resolving *.localhost

Chrome and Firefox handle `.localhost` domains automatically. For Safari or other browsers, you may need to add entries to `/etc/hosts`:

```bash
echo "127.0.0.1 myapp.localhost" | sudo tee -a /etc/hosts
```
